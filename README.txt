CRYPTVOX - VST3 (JUCE)
Budowanie bez instalowania czegokolwiek:
1. Nowe repo na GitHubie, wrzuc cala zawartosc tego folderu (razem z .github).
2. Zakladka Actions -> Build VST3 -> pobierz artifact (Windows / macOS).
3. Skopiuj plik .vst3: Windows C:\Program Files\Common Files\VST3 | macOS /Library/Audio/Plug-Ins/VST3
4. REAPER: Options > Preferences > Plug-ins > VST > Re-scan.
